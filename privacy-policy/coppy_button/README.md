# 「コピーボタン」プライバシーポリシー

制定日 2026年11月12日

本ポリシーは、[@fuwa10](https://github.com/fuwa10) が開発する Chrome 拡張機能「コピーボタン」に適用されます。この拡張機能は、Anison Generation の検索結果から、DJ ソフトのタグ付けに使う作品情報をコピーするためのものです。

## 取り扱うデータと利用目的

- **貼り付けたテキスト**は、対象ページで利用者が貼り付け操作をしたときに参照します。検索欄にフォーカスがない場合、テキストを検索欄に入力し、サイトの検索フォームから Anison Generation に検索語として送信します。
- **検索結果のテキスト**は、利用者がコピーボタンを押したときに、その行のジャンル、使用作品、種別をつなげて端末のクリップボードに書き込むために使います。「TV」は「TVA」に変換します。

## 保存と第三者への提供

拡張機能は、貼り付けたテキストや検索結果を拡張機能のストレージに保存せず、開発者のサーバーにも送信しません。コピーしたテキストは、端末のクリップボードの機能に従って保持されます。

検索フォームから送信された検索語の取り扱いは、Anison Generation の運営者によります。HTTP で同サイトを開いて検索した場合、その検索リクエストは暗号化されません。HTTPS で開いた場合、検索リクエストは HTTPS で送信されます。

拡張機能はユーザーデータを販売せず、広告、アクセス解析、信用力の判断、融資の目的で利用または提供しません。ユーザーデータの利用と送信は、上記の検索とタグ付けの機能に限ります。

## サイトへのアクセス

拡張機能は、検索欄の操作、検索結果の読み取り、コピーボタンの表示のために、Anison Generation の `http://anison.info/data/*` と `https://anison.info/data/*` で動作します。
